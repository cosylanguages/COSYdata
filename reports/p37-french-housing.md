# P37 French housing definitions and examples
P37 filled the definitions and examples for **208 French housing entries** that had neither.
## Scope
The batch covers the French `housing` theme: rooms, furniture, appliances, rental terms, buildings, maintenance and household tasks.
## Sources checked
- Le Robert and Larousse entries for the French definitions
- French Wiktionary for spelling and gender
- The repository's existing French housing entries for terminology and register
## Verification
- Each definition is a short French description of the headword.
- Each example is a French sentence containing the headword.
- No definition repeats the headword.
- No example uses a fixed template.
## Result
- Entries updated: **208**
- Entries total: **31,568**
- Findings: **11,292** (from 11,708)
- Missing definitions: **1,035**
- Missing examples: **1,861**
