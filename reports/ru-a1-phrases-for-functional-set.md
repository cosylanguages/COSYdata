# Useful A1 Model Sentences / Phrases Found in A0-A1 Audit

- `поднимите руку`: поднять руку чтобы задать вопрос в классе
- `откройте книгу`: открыть учебник на нужной странице
- `закройте книгу`: закрыть учебник после окончания задания
- `слушайте внимательно`: слушать учителя с большим вниманием
- `повторите за мной`: произнести снова те же слова
- `соблюдайте тишину`: не разговаривать во время теста
- `напишите на доске`: написать правильный ответ на доске
- `прочитайте текст`: прочитать слова на странице
- `работайте в парах`: выполнять упражнение вместе с другом
- `вы поняли`: спросить понятен ли смысл урока
