# Statistics

The dataset, counted. Reads `stats.json` and renders totals, CEFR levels, field
coverage, languages, word forms and themes.

## Files

| File | Role |
| --- | --- |
| `index.html` | Markup only. Empty containers, no numbers. |
| `statistics.css` | Layout and accents. Colour, spacing and type come from tokens. |
| `statistics.js` | Fetches the data file and fills the containers. |

## What it needs

Everything below is read at runtime. Nothing else in the repository is touched.

```
products/statistics/          this folder, self-contained
shared/cosy-theme.js          theme toggle
shared/vendor/css/fonts.css   self-hosted fonts
shared/vendor/tokens.css      design tokens
shared/vendor/css/ecosystem-strip.css
shared/vendor/js/ecosystem-strip.js
stats.json                    the numbers, generated by npm run build:stats
```

Paths are relative, so the folder works at this depth. To move it deeper, move
the `../../` prefix of the shared paths with it.

## Editing

Change `stats.json` through its generator, never here:

```
npm run build:stats
```

The page renders whatever the file says. If a value is missing, the page leaves
the slot blank rather than inventing one.

## Checking

```
npm run check:stats        # the file is fresh
npm run test:stats         # the file and the page agree
```
